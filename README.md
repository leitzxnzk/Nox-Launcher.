<h1>Nox Launcher</h1>
<h4>**Nox** é um launcher de jogos leve e simples, desenvolvido para reunir seus jogos em uma interface organizada e fácil de usar. A ideia é tornar o acesso aos jogos mais rápido e prático, sem menus complicados ou recursos desnecessários.

O projeto ainda está em desenvolvimento e novas funcionalidades, melhorias visuais e recursos serão adicionados ao longo do tempo. O Nox busca ser uma alternativa simples para quem quer ter sua biblioteca de jogos organizada em um único lugar.
</h4>
